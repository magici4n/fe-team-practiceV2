WON 실습뱅킹 API 명세서

이 문서는 실습용 은행 앱 목업 화면(홈, 이체, 거래내역조회)이 필요로 하는 API를 정의합니다. 아래 명세를 그대로 구현하면, 목업 화면의 더미 데이터를 실제 서버 응답으로 교체할 수 있습니다.

Base URLhttp://localhost:4000/api
Content-Typeapplication/json
인증실습 범위에서는 생략 (로그인/토큰 없이 호출 가능)
CORS모든 origin 허용 (실습 목적)
에러 응답 형식{ "message": "에러 설명" }

계좌 (Accounts)

GET /api/accounts 전체 계좌 목록 조회

로그인한 사용자가 보유한 모든 계좌 목록을 반환합니다. 홈 화면의 계좌 리스트, 총자산 계산, 이체 화면의 출금계좌 선택 드롭다운에 사용됩니다.

200 OK조회 성공
Response Body
[
  {
    "id": "acc1",
    "nickname": "우리 첫급여통장",
    "accountNo": "1002-***-123456",
    "type": "입출금",
    "balance": 2384560
  },
  {
    "id": "acc2",
    "nickname": "우리 SUPER주거래통장",
    "accountNo": "1002-***-789012",
    "type": "저축예금",
    "balance": 15200000
  }
]
GET /api/accounts/:accountId 단일 계좌 상세 조회

특정 계좌 하나의 상세 정보를 반환합니다.

Path Parameters
이름타입설명
accountIdstring조회할 계좌의 id (예: acc1)
200 OK조회 성공
Response Body
{
  "id": "acc1",
  "nickname": "우리 첫급여통장",
  "accountNo": "1002-***-123456",
  "type": "입출금",
  "balance": 2384560
}
404 Not Found존재하지 않는 계좌 id
Response Body
{ "message": "계좌를 찾을 수 없습니다" }

거래내역 (Transactions)

GET /api/transactions 거래내역 목록 조회

거래내역 목록을 최신순으로 반환합니다. 홈 화면의 최근 거래 미리보기와 거래내역조회 화면의 필터링에 사용됩니다. 쿼리 파라미터로 계좌·입출금 유형을 필터링할 수 있습니다.

Query Parameters
이름타입필수설명
accountIdstring선택특정 계좌의 거래만 조회. 생략하면 전체 계좌
typestring선택in(입금) / out(출금). 생략하면 전체
limitnumber선택반환할 최대 건수. 생략하면 전체 반환
Example Request
GET
/api/transactions?accountId=acc1&type=out&limit=10
200 OK조회 성공 (조건에 맞는 결과가 없으면 빈 배열)
Response Body
[
  {
    "id": 1,
    "accountId": "acc1",
    "date": "2026-08-23",
    "time": "09:12",
    "desc": "스타벅스 강남점",
    "type": "out",
    "amount": 5800,
    "balanceAfter": 2384560,
    "status": "done"
  }
]
GET /api/transactions/:id 거래 상세 조회

거래내역 항목 클릭 시 뜨는 상세 정보 시트에 사용됩니다.

Path Parameters
이름타입설명
idnumber조회할 거래의 id
200 OK
Response Body
{
  "id": 1,
  "accountId": "acc1",
  "date": "2026-08-23",
  "time": "09:12",
  "desc": "스타벅스 강남점",
  "type": "out",
  "amount": 5800,
  "balanceAfter": 2384560,
  "status": "done"
}
404 Not Found
Response Body
{ "message": "거래내역을 찾을 수 없습니다" }

이체 (Transfer)

GET /api/transfer/lookup 예금주 조회

이체 화면 1단계에서 받는 분의 계좌번호를 입력했을 때, 예금주명을 조회합니다. 실제 서비스라면 은행 간 실명조회 시스템을 거치지만, 이 실습 API는 미리 등록된 더미 계좌번호 목록에서 조회합니다.

Query Parameters
이름타입필수설명
bankstring필수받는 은행명 (예: 우리은행)
accountNostring필수받는 계좌번호 (숫자만, - 없이)
Example Request
GET
/api/transfer/lookup?bank=우리은행&accountNo=1002123456789
200 OK등록된 계좌를 찾음
Response Body
{ "ownerName": "김민준" }
404 Not Found등록되지 않은 계좌번호
Response Body
{ "message": "계좌 정보를 확인할 수 없습니다" }
💡 실습용 더미 계좌번호: 1002123456789(김민준), 1002987654321(이서연), 1102555666777(박지훈)
POST /api/transfers 이체 실행

이체를 실제로 실행합니다. 출금 계좌의 잔액을 차감하고, 새 거래내역을 생성합니다. 서버는 클라이언트가 보낸 금액을 그대로 신뢰하지 않고, 잔액과 최소 금액을 서버에서 다시 검증합니다.

Request Body
이름타입필수설명
fromAccountIdstring필수출금할 내 계좌 id
toBankstring필수받는 은행명
toAccountNostring필수받는 계좌번호
toOwnerNamestring필수받는 분 예금주명 (lookup 결과)
amountnumber필수이체 금액 (1,000원 이상)
Example Request
Request Body
{
  "fromAccountId": "acc1",
  "toBank": "우리은행",
  "toAccountNo": "1002987654321",
  "toOwnerName": "이서연",
  "amount": 30000
}
201 Created이체 성공
Response Body
{
  "transaction": {
    "id": 8,
    "accountId": "acc1",
    "date": "2026-08-23",
    "time": "14:32",
    "desc": "이서연",
    "type": "out",
    "amount": 30000,
    "balanceAfter": 2354560,
    "status": "done"
  },
  "account": { "id": "acc1", "balance": 2354560 }
}
400 Bad Request잔액 부족 / 최소금액 미만 / 필드 누락
Response Body
{ "message": "잔액이 부족합니다" }
404 Not Found존재하지 않는 출금 계좌
Response Body
{ "message": "출금 계좌를 찾을 수 없습니다" }
